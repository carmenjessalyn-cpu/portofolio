Overview

About the Project

Sorak.in is a standalone software system developed as a web-based concert ticket booking platform. This project was designed to meet the needs of the Indonesian public in accessing, selecting, and purchasing concert tickets digitally in an easy, safe, and efficient manner.

The system is designed to be an end-to-end solution in the music entertainment ecosystem, connecting concert promoters as event providers with the audience as ticket consumers. Users can access various features, from viewing upcoming concert lists, booking tickets, making payments via Virtual Account, to getting information on physical wristband exchanges.

Problem

The Problem Statement

Customers aged 15-40 are accustomed to using digital platforms but require a responsive interface that prioritizes speed and personal data security. On the other hand, concert management needs access to accurate ticket sales and revenue reports for decision-making.

The Challenge

The challenge was to create a platform accessible via modern browsers on both desktop and mobile devices, ensuring a user-friendly interface, and handling real-time data synchronization such as ticket stock counters and payment timers.

The Goal

To build an integrated system serving two main user groups: customers (audience) and concert management, with comprehensive features ranging from account registration and ticket booking, to the automated issuance of unique digital invoices formatted as SKR-XXXXXXXX.

Process

Design Process

The design development of Sorak.in went through the stages of system requirements identification and structured visual interface design.

Empathize

We analyzed two main user characteristics: customers needing easy concert catalog exploration, and concert management requiring accurate event management, ticket tiering, and transaction data monitoring.

Define

We formulated the system information flow, establishing crucial interfaces such as registration, login, the main homepage, concert search, ID-compliant data entry, and m-BCA payment guidelines.

Ideate

In the ideation stage, we designed various supporting functionalities such as a wishlist addition, a countdown timer for transactions, and an order status monitoring system (Success, Pending, or Expired).

Prototype

We created UI/UX mockup designs and interactive prototypes using Figma, covering the entire user journey from selecting concerts, validating ID, checking out orders, to viewing E-Invoice details.

Testing

We conducted thorough software testing, including Unit Testing, System Testing, Security Testing, and User Acceptance Testing (UAT) to ensure the application is ready to use and safe for users.

Reflection

What I Learned

The Sorak.in project taught the importance of structuring a solid information system architecture and targeted UI/UX integration. We learned that interface design is not just about aesthetics, but also about providing clear instructions, maintaining transaction security, and ensuring comfortable user flows for two different sides of the market.
